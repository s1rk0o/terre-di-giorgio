## 🍃 Project Overview

This digital platform represents the sustainable ecosystem of Terre di Giorgio, featuring:

* **Heritage & Estate (Il Territorio):** History and commitment to organic agriculture in Val d'Orcia.
* **Boutique Hospitality (Agriturismo Palazzetta):** Accommodation, organic gastronomy, and seasonal experiences.
* **Artisanal Products (I Nostri Prodotti):** Organic Extra Virgin Olive Oil, Calus Red Wine, Diana Rosé, Grappa, and Tuscan Saffron.
* **ESG & Sustainability (Sostenibilità):** Comprehensive 2026 ESG metrics tracking Environmental, Social, and Governance performance.

---

## ✨ Key Features

* 📱 **Fully Responsive Design:** Optimized for both desktop displays and mobile devices.
* 🌐 **Bilingual Support (EN / IT):** Seamless language toggling implemented with pure JavaScript.
* 📄 **Integrated ESG Report:** Instant PDF download for the full Sustainability & Audit Report 2026.
* 🦅 **Custom Branding:** Bespoke favicon and luxury visual identity inspired by Tuscan heritage.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox, CSS Grid, Media Queries, Clamp typography)
* **Scripting:** Vanilla JavaScript (Language switcher, scroll header, interactive elements)
* **Hosting:** GitHub Pages (Automated deployment pipeline via GitHub Actions)
* **Typography:** Cormorant Garamond & Inter (Google Fonts)
